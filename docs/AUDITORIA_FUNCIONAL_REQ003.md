# Auditoría Funcional REQ-003

## Requisito

REQ-003: Filtrado de productos por fecha.

## Criterios de aceptación

### CA-01
El sistema permite consultar productos utilizando una fecha.

**Resultado:** PASS

### CA-02
El sistema devuelve únicamente los productos que cumplen con la fecha indicada.

**Resultado:** PASS

### CA-03
El sistema maneja correctamente una consulta sin resultados.

**Resultado:** PASS

## Procedimiento de prueba

1. Ejecutar la aplicación.
2. Realizar una consulta utilizando una fecha válida.
3. Verificar los productos obtenidos.
4. Realizar una consulta con una fecha sin coincidencias.
5. Verificar que el sistema maneje correctamente el resultado.

## Resultado general

El requisito REQ-003 fue validado mediante los criterios de aceptación definidos.
